# Checklist de validation V1 mobile

## Parcours
- [ ] Accueil affiché sans zoom.
- [ ] Bouton Démarrer fonctionne.
- [ ] Évaluation accessible.
- [ ] Test guidé fonctionne.
- [ ] Boutons du test désactivés pendant la suspension.
- [ ] Résultat correct.
- [ ] Programmation créée.
- [ ] Dates réelles affichées.
- [ ] Timer démarre.
- [ ] Échauffement intégré présent.
- [ ] P10 asymétrique affichée correctement.
- [ ] Bilan enregistré.
- [ ] Fin de cycle accessible après cycle terminé.

## Calendrier
- [ ] Départ du cycle = date du jour.
- [ ] 2 séances : J+0 / J+3.
- [ ] 3 séances : J+0 / J+2 / J+5.
- [ ] Séance manquée détectée.
- [ ] Report disponible.
- [ ] Report décale la suite.
- [ ] Pas de compression de séances.

## Notifications
- [ ] Page Réglages accessible.
- [ ] Permission demandée.
- [ ] Notification principale envoyée.
- [ ] Relance douce envoyée si activée.
- [ ] Pas de spam de notifications.
- [ ] Clic notification ouvre l’app.

## PWA
- [ ] Installable sur Android.
- [ ] Icône correcte.
- [ ] Splash correct ou acceptable.
- [ ] Fonctionne hors ligne après premier chargement.
